

# Linear Regression from Scratch

## Overview
This project demonstrates the internal mechanics of Linear Regression by
implementing the algorithm manually without using machine learning libraries
such as sklearn or statsmodels.

## Dataset
Housing Prices Dataset (Kaggle)

## Objective
Predict house prices using Linear Regression implemented from scratch.

## Constraints Followed
✔ No sklearn / statsmodels  
✔ Only numpy + pandas  
✔ Manual Gradient Descent  

## Implementation Steps
1. Data preprocessing  
2. Encoding categorical variables  
3. Feature scaling  
4. Linear model prediction  
5. MSE loss computation  
6. Gradient Descent training  
7. Model evaluation  

## Key Learning Outcomes
• Understanding prediction mechanics  
• Loss minimization via Gradient Descent  
• Importance of feature scaling  
• Prevention of information leakage
